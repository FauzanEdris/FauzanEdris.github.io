# Contributor and AI guidance

Read `README.md`, `docs/PROJECT_CONTEXT.md`, `docs/DECISIONS.md`, and `docs/STATUS.md` before making significant changes. These files are tool-neutral and are the shared source of project context for any assistant or contributor.

Follow the user's instructions, preserve existing work, and update the relevant documentation when architecture, decisions, verification, or status changes. Do not invent personal facts or publish private information. Do not deploy, push, or alter GitHub settings without the user's authorization.
